## Slide 03 — Lösung & USPs · Martin

**Eine Plattform. Alle Daten. Deine KI.**

> Wir bauen keine neue Gesundheits-App. Wir bauen den Ort, an dem alle anderen zusammenkommen.

### USP 1 — Health Vault *(Open Source)*

Deine Daten. Du wählst wo.

- **Gerät** — Nur auf deinem Handy *(Standard, ausgewählt)*
- **Exodus Cloud** — DSGVO-konform · EU-Server
- **Eigene Cloud** — iCloud · OneDrive · Dropbox · Nextcloud · Self-hosted

### USP 2 — Bring Your Own AI

| Option | Beispiele |
|---|---|
| Lokal (Open Source KI) | Ollama |
| Smartphone | Apple Intelligence, Gemma |
| Cloud optional (opt-in) | ChatGPT, Claude, Gemini |

> **Standard ist immer lokal.**

### USP 3 — Persönlicher Health-Agent *(OpenClaw)*

Datenfluss:
1. Exodus Vault
2. MCP Skill-Pack
3. OpenClaw Agent
4. Shop → Warenkorb
5. Bestätigung durch dich

> Dein Agent arbeitet für dich. Nur mit deiner Freigabe.

### Was Exodus NICHT ist

- Kein weiteres Silo
- Keine Black Box
- Kein US-Cloud-Zwang
- Keine App, die deine Daten besitzt

## Slide 06 — USP & Wettbewerb · Felix + Martin

**Das gibt es so kein zweites Mal.**

> Kein anderer Anbieter weltweit kombiniert lokale KI by default, offenen Agentic Layer, EU-DSGVO als Architektur und den Supplement-Kanal in einer Plattform.

### Feature-Vergleich: Exodus vs. Andere

| Feature | Exodus | Andere |
|---|---|---|
| Lokal-first KI (default) | ✅ | ✗ |
| Bring Your Own AI | ✅ | ✗ |
| Offener Agentic Layer | ✅ | ✗ |
| Labor + Wearables + Arztbriefe | ✅ | teilweise |
| EU-DSGVO als Architektur | ✅ | ✗ |
| Supplement-Kanal | ✅ | ✗ |
| Open Source bevorzugt | ✅ | ✗ |

### Was kein anderer bietet

1. Lokal-first KI — deine Daten, dein Gerät, dein Modell
2. Bring Your Own AI — Llama, Mistral, Apple Intelligence, eigener Endpoint
3. Offener Agentic Layer — KI-Agenten können mit Freigabe für dich handeln
4. Labor + Wearables + Arztbriefe + Supplements — alles in einer Timeline
5. EU-DSGVO als Architektur, nicht als Checkbox
6. Open Source bevorzugt — kein Vendor Lock-in

## Slide 08 — Revenue · Martin

**Wir verkaufen keine App. Wir verkaufen Connections.**

### Phase 1 — Abo-Subscription (Health Data Vault)

Die ersten Connections kostenlos. Wer mehr verbinden will — zahlt monatlich.

| Tier | Inhalt |
|---|---|
| Free | 2 Connections + 5 Labortests (PDF-Upload) |
| Premium | Mehr Connections, KI-Erklärungen, Agentic Layer + Beratungsgespräche |
| Family | Mehrere Profile, eigene KI-Endpunkte |

### Phase 2 — Arzt-Beratung & Heilpläne (Plattform-Vermittlung)

Personalisierte Pläne auf Datenbasis. Clinician-in-the-Loop: KI schlägt vor — Arzt gibt frei.

- Heilplan-Erstellung
- Beratungsgespräche (Chat)
- Provision pro Beratung

### Phase 3 — Supplements & Longevity (Produkt-Verkauf)

Personalisiert auf Gesundheitsprofil. Supplement-Hersteller · Custom-Abfüllung · In-App oder via Agent.

| Produkt | Detail |
|---|---|
| Eigene Produkte | Custom-Abfüllung |
| Kooperationen | Supplement-Hersteller (z.B. Biogena) |
| In-App-Kauf | KI empfiehlt → Agent bestellt → du bestätigst |

> **Synergie:** Mehr Daten → bessere Pläne → passendere Supplements → mehr Vertrauen → mehr Connections
